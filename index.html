Any Time To Work

Prototype interactif : missions courtes (4 jours maximum) dans le tertiaire et l'événementiel.

Passez d'une interface à l'autre pour tester les deux côtés. Une candidature envoyée côté candidat apparaît chez le pro.

Données d'exemple. Rien n'est envoyé ni enregistré : tout s'efface en rechargeant la page.
